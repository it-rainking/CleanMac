# 🚀 Quick Start - CleanMac Web Interface

## In 3 semplici passi:

### 1️⃣ Installa Node.js (se non ce l'hai già)
Scarica e installa da: https://nodejs.org/
Scegli la versione **LTS** (Long Term Support)

### 2️⃣ Avvia l'interfaccia web
Doppio click su:
```
start-web.command
```

### 3️⃣ Usa CleanMac dal browser
Il browser si aprirà automaticamente su:
```
http://localhost:3000
```

## ⚙️ Installazione manuale (opzionale)

Se preferisci il terminale:

```bash
cd /Volumes/Dati/Dropbox/GitHub/CleanMac
npm install
npm start
```

Poi apri: http://localhost:3000

---

## 🆘 Problemi?

**"Node.js non trovato"**
→ Installa Node.js da nodejs.org

**"Porta già in uso"**
→ Modifica la porta in `server.js` (cambia `PORT = 3000`)

**"Cannot find module"**
→ Esegui `npm install` nella cartella CleanMac
