## ✨ NUOVE FUNZIONALITÀ

### 🎯 Selezione Interattiva Post-DryRun

Dopo aver eseguito il DRY RUN, CleanMac v4.2 ora ti permette di **scegliere quali categorie di operazioni eseguire**, offrendo massima flessibilità e controllo.

#### Dialog a 3 Opzioni

Al termine del DRY RUN, vedrai un dialog con:

1. **❌ Annulla**
   - Esce senza eseguire nulla
   - Puoi revisionare i report generati
   - Ri-esegui quando vuoi per procedere

2. **🎨 Personalizza Selezione** (CONSIGLIATO)
   - Apre dialog multi-select categorie
   - Scegli liberamente tra: 🗑️ Pulizia, ⚡ Performance, 📊 Analisi
   - Performance pre-selezionata di default (migliora velocità senza eliminare file)

3. **🚀 Esegui Tutto**
   - Esegue tutte le 29 operazioni
   - Comportamento classico v4.0/v4.1
